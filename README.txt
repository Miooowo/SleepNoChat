SleepNoChat
===========

Client mod that hides chat messages and the chat input while sleeping,
and keeps the Leave Bed button.

Forge 1.20.1 (JDK 17)
  gradlew.bat build
  -> build\libs\sleepnochat-1.0.0.jar

NeoForge 1.21.1 (JDK 21)
  cd neoforge-1.21.1
  gradlew.bat build
  -> neoforge-1.21.1\build\libs\sleepnochat-neoforge-1.21.1-1.0.0.jar

Put the matching jar into that instance's mods folder. Do not mix loaders.
